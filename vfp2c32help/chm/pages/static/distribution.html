Distribution

VFP2C32 Package

The distribution contains the following directories:

vfp2c32Contains the FLL and all supporting files.
vfp2c32examplesContains an example project.
vfp2c32frontVFP2C32 Front is a supporting program which translates C struct, union and enum types into VFP code.
vfpsrvhostVFPSrvHost is a standalone C project to host VFP COM objects in a windows service.

Integration into you project

Add vfp2c32.fll/vfp2c64.fll and vfp2c.h to your project - both excluded from the application/executable.
If you need to pass C style arrays to a C library you'll want to have a look at the classes defined in vfp2carray.prg and also include it.

vfp2c32t.fll/vfp2c64t.fll is the threadsafe version of the library, you can use it in multithreaded VFP COM dlls.

If you intend to use the Intel Hyperscan functions, add also the hyperscan.h file for the needed #DEFINE's.

Initialization/cleanup of the library

Copy code
&& somewhere at your programs startup code
#INCLUDE vfp2c.h
SET LIBRARY TO vfp2c32.fll ADDITIVE 
&& or if using VFP Advanced 64 bit 
SET LIBRARY TO vfp2c64.fll ADDITIVE

Deployment 32 bit

Place a copy of vfp2c32.fll/vfp2c32t.fll and msvcr71.dll in your application directory structure, NOT in Windows\System32 or any other system directory.

Deployment 64 bit

Place a copy of vfp2c64.fll/vfp2c64t.fll and msvcr100.dll in your application directory structure, NOT in Windows\System32.

Intel Hyperscan Deployment

If you use any of the Hyperscan functions, deploy a copy of the vfp2c32/hyperscan/x86/hs.dll and vfp2c32/hyperscan/x86/hs_runtime.dll for 32-bit or vfp2c32/hyperscan/x64/hs.dll and vfp2c32/hyperscan/x64/hs_runtime.dll for 64-bit in your application directory, these are precompiled binaries from the official Intel Hyperscan sourcecode on GitHub (https://github.com/intel/hyperscan), plus 2 minor bugfixes to the sources: one which fixes missing function exports and the other fixes compilation errors of regular expressions with included word boundary conditions ("\b"). The hyperscan library itself has a dependency on the Visual C++ Runtime v14 (https://learn.microsoft.com/de-de/cpp/windows/latest-supported-vc-redist?view=msvc-170), so this needs to be installed on the target system aswell.

The hyperscan dll's are loaded on the fly on first use, if you don't call any hyperscan functions you don't have to deploy the hs.dll/hs_runtime.dll files nor the Visual C++ v14 runtime. Because of dependencies in the Visual C++ v14 runtime itself the hyperscan functions are not compatible with older operating systems, at least Windows Vista is required, on older operating systems the hs.dll will simply fail to load because of missing functions imports from OS system dll's.
