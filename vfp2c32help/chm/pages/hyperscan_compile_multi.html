Hyperscan_compile_multi

Compiles a single or multiple regular expressions into a hyperscan database.

Hyperscan_compile_multi(@caExpressions, @nDB, naFlags, nMode[, @aExtendedFlags])

Parameters

@caExpressions

A single regular expression or an array of regular expressions.

Note

If an array of multiple expression's is passed one can specify the expression identifier in the 2nd column.
When passing a 1 dimensional array the expression identifier is autogenerated just the row number.
The expression identifier is reported back in the various Hyperscan_scan function result cursors in the "match_id" field.

@nDB

A variable by reference in which a handle to the compiled database is returned.

naFlags

A single numeric flag value or an array by reference of flags for each regular expression used to compile the database.

FlagDescription
HS_FLAG_CASELESS
HS_FLAG_DOTALL
HS_FLAG_SINGLEMATCH
HS_FLAG_ALLOWEMPTY
HS_FLAG_UTF8
HS_FLAG_UCP
HS_FLAG_PREFILTER
HS_FLAG_COMBINATION
HS_FLAG_QUIET

Note

When passing a single numeric flag parameter it is used for all expressions passed in aExpressions.

Note

The hyperscan flag HS_FLAG_SOM_LEFTMOST is added automatically, without this flag it would be impossible to
extract the regular expression out of the scanned data.

Copy code
LOCAL laRegs[2], laFlags[2]
m.laRegs[1]  = '^PROCEDURE\s+\w+$'
m.laRegs[1]  = '^ENDPROC\b'
m.laFlags[1] = HS_FLAG_CASELESS + HS_FLAG_MULTILINE && flags used for 1st regular expression
m.laFlags[2] = HS_FLAG_CASELESS +HS_FLAG_MULTILINE
nMode (additional)

A mode to compile the regular expression.

Either HS_MODE_BLOCK or HS_MODE_STREAM.

Note

When compiling in streaming mode the following flags can be added to control the lookback buffer size.

HS_MODE_SOM_HORIZON_SMALLLimits the lookback buffer to 64 kilobytes.
HS_MODE_SOM_HORIZON_MEDIUMLimits the lookback buffer to 2 gigabyte, but the real
lookback capability is controlled by the buffersize passed to Hyperscan_scan / Hyperscan_scan_files
@aExtendedFlags (optional)

An array of objects with extened flags to control pattern matching behaviour.

PropertyDescription
min_offsetThe minimum end offset in the data stream at which this expression should match successfully.
max_offsetThe maximum end offset in the data stream at which this expression should match successfully.
min_lengthThe minimum match length (from start to end) required to successfully match this expression.
edit_distanceAllow patterns to approximately match within this edit distance.
hamming_distanceAllow patterns to approximately match within this Hamming distance.

Copy code
LOCAL laExtendedFlags[3], loExtFlags
m.loExtFlags = CREATEOBJECT('Empty')
ADDPROPERTY(m.loExtFlags, 'min_offset', 32)
ADDPROPERTY(m.loExtFlags, 'max_offset', 64)
m.laExtendedFlags[1] = m.loExtFlags
m.loExtFlags = CREATEOBJECT('Empty')
ADDPROPERTY(m.loExtFlags, 'min_offset', 128)
ADDPROPERTY(m.loExtFlags, 'max_offset', 256)
m.laExtendedFlags[2] = m.loExtFlags
m.loExtFlags = CREATEOBJECT('Empty')
ADDPROPERTY(m.loExtFlags, 'min_offset', 512)
ADDPROPERTY(m.loExtFlags, 'max_offset', 1024)
m.laExtendedFlags[3] = m.loExtFlags

Return Value

A hyperscan return code.
HS_SUCCESS (0) on success otherwise the errorcode.

Example

Copy code
LOCAL laRegs[2,2], lnRet, lnDB, lnMode, loExtendedFlags

m.lnDB = 0
m.laRegs[1,1] = '\bRegularExpression1\b'
m.laRegs[1,2] = 1
m.laRegs[2,1] = '\bRegularExpression2\b'
m.laRegs[2,2] = 5

m.lnRet = Hyperscan_compile(@m.laRegs, @m.lnDB, HS_FLAG_MULTILINE, ;
HS_MODE_STREAM + HS_MODE_SOM_HORIZON_SMALL)

IF m.lnRet != 0
    AERROREX('laError')
    ? laError[1], laError[2], laError[3]
ENDIF
