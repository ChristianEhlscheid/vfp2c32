Hyperscan_free_scratch

Frees scratch memory allocated with Hyperscan_alloc_scratch.

Hyperscan_free_scratch(nScratch)

Parameters

nScratch

A handle to scratch memory previously allocated with Hyperscan_alloc_scratch.

Return Value

A hyperscan return code.
HS_SUCCESS (0) on success otherwise the errorcode.

Remarks

All flags and return code #DEFINE's are supplied in the "hyperscan.h" file.
