SQLCreateTableTypeCursor

Creates an empty cursor of the specified registered SQL Server table type.

You can fill this cursor and then pass it a SQLExecEx call for TVP (table valued parameters) parameters.

SQLCreateTableTypeCursor(nConnection, cCatalog, cSchema, cType, cCursor)

Parameters

nConnection

A valid ODBC connection handle.

cCatalog

The catalog name of the type.

cSchema

The schema name of the type.

cType

The name of the table type.

cCusor

The name of the cursor to be created.

Return Value

Returns always 1.

Remarks

Pass the same parameters for the parameters cCatalog, cSchema and cType as passed to the SQLRegisterTableType function.
