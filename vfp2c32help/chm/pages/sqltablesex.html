SQLTablesEx

Creates a cursor with table, catalog, or schema names, and table types, stored in a specific data source.

SQLTablesEx(nConnection, cCatalog, cSchema, cTable, cTableType, cCursor [, nFlags [, nScope]])

Parameters

nConnection

A valid ODBC connection.

cCatalog

The catalog of the remote database, acts as a filter.
Either a valid catalog name, an empty string or .NULL..

cSchema

The schema in the remote database, acts as a filter.
Either a valid schema name, an empty string or .NULL..

cTable

The table, table type or view name in the remote database, acts as a filter.
Either a valid schema name, an empty string or .NULL..

cTableType

The type of table, acts as a filter.
TABLE, TABLE TYPE or VIEW.

cCusor

The name of the cursor to be created.

nFlags (optional)

Will set statement attributes before executing the function.
When passing SQL_ATTR_METADATA_ID this will affect how the cCatalog, cSchema, and cTable parameters are processed.

nScope (optional)

When passed sets the SQL_SOPT_SS_NAME_SCOPE (Microsoft SQL Server only) statement attribute.
When you want to enumerate the table type's in SQL Server pass SQL_SS_NAME_SCOPE_TABLE_TYPE.

Return Value

1 if the function succeeded or -1 if it fails.
