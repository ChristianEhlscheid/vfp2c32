FreeRefArray

Frees all memory allocated for the passed in C style array.

This is meant to be only used for C style arrays that contain
pointers to their respective data.

The function loops over the elements from index position nStartElement to nElements and calls HeapFree if a valid pointer is stored at the indexed position to free the memory and the setting the pointer to 0, effectivly cleaning up the array properly without creating memory leaks.

FreeRefArray(nAddress, nStartElement, nElements)

Parameters

nAddress

The base address of the array.

nStartElement

default = 1

The index of the first element to free.

nElements

The total number of elements in the array.

Return Value

.T. if all elements were freed successful, .F. otherwise.
