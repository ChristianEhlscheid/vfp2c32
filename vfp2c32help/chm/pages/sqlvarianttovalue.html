SQLVariantToValue

Converts a field of type SQL_SS_VARIANT retrieved from SQL Server via SQLExecEx into it's equivalent FoxPro type.

SQLVariantToValue(cValue [, @nType [, @nSize [, @nScale]]])

Parameters

cValue

The value retrieved from SQL Server.

Note

Blob fields of a cursor have to be passed by reference.

@nType (optional)

stores the ODBC numeric data.

@nSize (optional)

stores the size in bytes.

@nScale (optional)

stores the fractional digits.

Return Value

Returns the converted value.
