ValueToSQLVariant

Converts a FoxPro value into binary value for storage into a SQL_SS_VARIANT binary value for storage inside SQL Server.

ValueToSQLVariant(cValue[, nSQLType [, nScale]])

Parameters

cValue

Any foxpro value permissable as a SQL_SS_VARIANT, more or less all FoxPro types with a size of less than 8000 bytes.

nSQLType (optional)

By default the corresponding type is deduced by the passed FoxPro type.
But if you retrieved some value in binary form (e.g. SQL_SS_TIME) and want to store that again you'll have to pass the type explicitly.

nScale (optional)

Only needed for storing certain binary types like SQL_SS_TIME, defines the number of fractional digits.

Return Value
