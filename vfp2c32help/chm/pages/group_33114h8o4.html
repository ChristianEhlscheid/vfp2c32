ODBC

Extended ODBC functions.

ASQLDataSourcesStores information about configured ODBC data sources into an array.
ASQLDriversStores information about the installed ODBC drivers into an array.
ChangeSQLDataSourceModifies a ODBC data source.
CreateSQLDataSourceCreates a ODBC data source.
DeleteSQLDataSourceDeletes a ODBC data source.
SQLCancelExReleases a prepared SQL statement.
SQLColumnPrivilegesExCreates a cursor of columns and associated privileges for the specified table.
SQLColumnsExCreates a cursor of column names in specified tables.
SQLCreateTableTypeCursorCreates an empty cursor of the specified registered SQL Server table type.

You can fill this cursor and then pass it a SQLExecEx call for TVP (table valued parameters) parameters.
SQLExecExExtended SQLEXEC, sends a SQL statement to the data source, where the statement is processed.
SQLForeignKeysExCreates a cursor of foreign keys in the specified table (columns in the specified table that refer to primary keys in other tables) or a cusor of foreign keys in other tables that refer to the primary key in the specified table.
SQLGetPropExExtended SQLGETPROP, retrieves ODBC connection attributes.
SQLPrepareExExtended SQLPREPARE.
Prepares a SQL statement for remote execution by SQLExecEx( ).
SQLPrimaryKeysExCreates a cursor with the column names that make up the primary key for a table.
SQLProcedureColumnsExCreates a cursor of input and output parameters, as well as the columns that make up the result set for the specified procedures.
SQLProceduresExCreate a cursor of procedure names stored in a specific data source.
SQLRegisterTableTypeRegisters a SQL Server table type in the library for use in SQLExecEx.
SQLSetPropExExtended SQLSETPROP, sets ODBC connection attributes.
SQLSpecialColumnsExCreates a cursor with the following information about columns within a table:
- the optimal set of columns that uniquely identifies a row in the table.
- columns that are automatically updated when any value in the row is updated by a transaction.
SQLTablePrivilegesExCreates a cursor of tables and the privileges associated with each table.
SQLTablesExCreates a cursor with table, catalog, or schema names, and table types, stored in a specific data source.
SQLVariantToValueConverts a field of type SQL_SS_VARIANT retrieved from SQL Server via SQLExecEx into it's equivalent FoxPro type.
ValueToSQLVariantConverts a FoxPro value into binary value for storage into a SQL_SS_VARIANT binary value for storage inside SQL Server.
