VFP2C32

A dummy function to check if the library is loaded.

VFP2C32()

Return Value

Returns .F.

Remarks

If the library is not loaded your FoxPro function is called. Once the library is loaded
the FLL function takes precedence and is called instead.

Example

FUNCTION VFP2C32()
SET LIBRARY TO LOCFILE('vfp2c32.fll')
RETURN .T.
ENDFUNC
