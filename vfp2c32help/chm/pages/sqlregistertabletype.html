SQLRegisterTableType

Registers a SQL Server table type in the library for use in SQLExecEx.

SQLRegisterTableType(nConnection, cCatalog, cSchema, cType[, nFlags])

Parameters

nConnection

A valid ODBC connection.

cCatalog

Pass a catalog name or an empty string for the current database of the type to be registered.

cSchema

Pass the schema name of the type to be registered.

cType

The name of the table type to be registered.

nFlags (optional)

default: SQLREGISTERTABLETYPE_CATALOG | SQLREGISTERTABLETYPE_SCHEMA

SQLREGISTERTABLETYPE_CATALOG
SQLREGISTERTABLETYPE_SCHEMA

Controls under which name the type is to be registered.

e.g.

SQLREGISTERTABLETYPE_CATALOG | SQLREGISTERTABLETYPE_SCHEMA results in
catalogname.schemaname.typename

SQLREGISTERTABLETYPE_CATALOG results in
catalogname..typename

SQLREGISTERTABLETYPE_SCHEMA results in
.schemaname.typename

Return Value

1 if the function succeeded or -1 if the function failed.
