Hyperscan_alloc_scratch

Allocates scratch memory for a hyperscan operation.

Hyperscan_alloc_scratch(nDb, @nScratch)

Parameters

nDb

A handle to a previously compiled database of regular expressions.

@nScratch

A variable by reference in which a handle to the allocated scratch memory space is returned.

Return Value

A hyperscan return code.
HS_SUCCESS (0) on success otherwise the errorcode.
